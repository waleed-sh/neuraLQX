# U(1) sampling

In a U(1) calculation, sampling means exploring assignments of charges to the graph's edges. With several gauge components, each edge carries one charge per component. The right proposal depends on whether those charges are independent or related by a gauge condition.

For an unconstrained [U(1) space](../hilbert/u1.md), a single component can change on its own. In a constructive gauge space, changing an independent charge can require changes on several dependent edges. neuraLQX provides both forms of sampling and keeps the complete configuration available to the wavefunction and operators.

## Unconstrained edge charges

For the usual cutoff $Q$, one component takes values

$$
q_{e,c}\in\{-Q,-Q+1,\ldots,Q\}.
$$

[`MetropolisLocal`](../../api/public/neuralqx/sampler/index.md#neuralqx.sampler.MetropolisLocal) selects one flat component site and replaces its charge by a different allowed charge. A proposal can therefore cross much of the local range in one attempt. [`MetropolisNeighbor`](../../api/public/neuralqx/sampler/index.md#neuralqx.sampler.MetropolisNeighbor) instead moves to the next or previous allowed value, with the boundary correction explained in [transition rules](transition-rules.md#moves-between-neighbouring-local-values).

Both choices sample the same Born distribution when they explore its support and have equilibrated. They can take very different times to explore it. A broad replacement can cross a charge barrier quickly but may be rejected often. Small steps can suit a smoothly varying amplitude but need more updates to travel across a wide range.

```python
import jax.numpy as jnp
import neuralqx as nqx

graph = nqx.graph.Grid2D(2, 2)
hilbert = nqx.hilbert.U1Hilbert(graph, cutoff=2, gauge_dimensions=3)

for constructor in (nqx.sampler.MetropolisLocal, nqx.sampler.MetropolisNeighbor):
    network = nqx.nn.RBM(
        hilbert.size, hidden_features=4, complex_output=False, rngs=0
    )
    sampler = constructor(hilbert, n_chains=4)
    state = nqx.vqs.VariationalState(
        sampler, network, n_samples=128, n_discard_per_chain=32, seed=5
    )
    samples, _ = state.sample()
    print(constructor.__name__, samples.shape)
    print(bool(jnp.all(hilbert.is_valid(samples))))
```

```text
MetropolisLocal (4, 32, 12)
True
MetropolisNeighbor (4, 32, 12)
True
```

The twelve entries are four edges in each of three components, following the [U(1) state layout](../hilbert/state-layouts.md). Neither constructor updates all components of an edge together. The selection is over flat component sites. Fractional labels also work on an unconstrained space when they are part of its declared local domain.

## Sampling a constructive gauge space

[`U1GaugeInvariantHilbert`](../../api/public/neuralqx/hilbert/index.md#neuralqx.hilbert.U1GaugeInvariantHilbert) identifies free charges and reconstructs the dependent charges from them. Let $f$ collect all independent charges across the gauge components, and let $R$ denote that reconstruction. A valid configuration is

$$
\sigma=R(f).
$$

The free entries remain present in the full configuration, so each allowed $f$ identifies exactly one configuration in the constructive space. Sampling can therefore propose in the smaller set of independent coordinates while evaluating the wavefunction on $R(f)$.

[`MetropolisU1Gauge`](../../api/public/neuralqx/sampler/index.md#neuralqx.sampler.MetropolisU1Gauge) uses [`U1GaugeRule`](../../api/public/neuralqx/sampler/index.md#neuralqx.sampler.U1GaugeRule) for this purpose. By default, it selects one free coordinate, draws a replacement uniformly from the local range, and reconstructs the dependent charges in every component. The replacement may equal the current value.

If the range has $d$ values, a selected coordinate has replacement probability $1/d$ in either direction. More generally, conditional on a chosen set of $r$ free coordinates, the replacement probability is $d^{-r}$. Coordinate selection is independent of the state, so the complete proposal is symmetric,

$$
q(R(f')\mid R(f))=q(R(f)\mid R(f')).
$$

There is no additional Hastings correction. The acceptance step compares the wavefunction amplitudes of the two reconstructed configurations. The dependent edges can change even when only one free charge was selected.

```python
import jax.numpy as jnp
import neuralqx as nqx

graph = nqx.graph.Grid2D(2, 2)
hilbert = nqx.hilbert.U1GaugeInvariantHilbert(
    graph, cutoff=2, gauge_dimensions=3, auto_constraint=True
)
network = nqx.nn.RBM(hilbert.size, hidden_features=4, complex_output=False, rngs=0)
sampler = nqx.sampler.MetropolisU1Gauge(hilbert, n_chains=8, n_edges=1)
state = nqx.vqs.VariationalState(
    sampler, network, n_samples=256, n_discard_per_chain=32, seed=11
)

samples, _ = state.sample()
print(hilbert.topology.n_free, hilbert.gauge_dimensions)
print(samples.shape)
print(bool(jnp.all(hilbert.is_valid(samples))))
```

```text
1 3
(8, 32, 12)
True
```

The square has one free base edge. With three components, the proposal chooses from three independent charge coordinates, while every stored configuration still contains all twelve charges. The topology and reconstruction relations are described in the [U(1) Hilbert guide](../hilbert/u1.md#supply-and-inspect-your-own-relations).

The default one-coordinate replacement can connect every configuration in this constructive space by successive moves when the wavefunction is nonzero throughout it. Exact wavefunction zeros can remove intermediate states from the Born support, so the usual [reachability considerations](transition-rules.md#assess-reachability-as-well-as-validity) still apply.

## Modular neighbour moves

Setting `adjacency=True` replaces a uniform redraw by a random step of one charge spacing in either direction. For the standard integer range, the update is

$$
q'=\operatorname{wrap}_Q(q+\varepsilon),
\qquad \varepsilon\in\{-1,+1\},
$$

where

$$
\operatorname{wrap}_Q(x)
=-Q+\bigl((x+Q)\bmod(2Q+1)\bigr).
$$

At the upper endpoint, a positive step wraps to $-Q$. The reverse negative step has the same probability, so the proposal remains symmetric. For other supported integer spacings, the update is one `q_step` with the corresponding modular local-index arithmetic.

This cyclic boundary is part of the constructive U(1) regularisation. The generic neighbour sampler instead has bounded endpoints. Choose the boundary convention together with the [Hilbert constraints](../hilbert/u1.md#what-the-finite-cutoff-means) and [holonomy operators](../lqx/u1.md#edge-and-loop-holonomies).

```python
import jax.numpy as jnp
import neuralqx as nqx

hilbert = nqx.hilbert.U1GaugeInvariantHilbert(
    nqx.graph.K5Graph(), cutoff=2, auto_constraint=True
)
network = nqx.nn.RBM(hilbert.size, hidden_features=4, complex_output=False, rngs=0)
sampler = nqx.sampler.MetropolisU1Gauge(
    hilbert, n_chains=4, n_edges=2, adjacency=True
)
state = nqx.vqs.VariationalState(
    sampler, network, n_samples=128, n_discard_per_chain=32, seed=13
)

samples, _ = state.sample()
print(sampler.rule.n_edges, sampler.rule.adjacency)
print(samples.shape)
print(bool(jnp.all(hilbert.is_valid(samples))))
```

```text
2 True
(4, 32, 10)
True
```

## How many charges should change?

`n_edges` counts distinct free charge coordinates selected from all gauge components together. It does not count the dependent entries changed by reconstruction, and it does not request that many updates in every component separately. If there are $F$ free base edges and $g$ components, the available coordinate count is $gF$.

For a nontrivial space, choose `n_edges` between one and $gF$. Larger proposals can move several independent charges at once, but their acceptance can decrease when the network strongly favours the current region. Start with the default and compare the [mixing diagnostics](diagnostics.md) before increasing it. With no free coordinates, the constructive space has a single configuration and every proposal stays there.

The default `sweep_size` still uses the full `hilbert.size`. It is not automatically reduced to the number of free coordinates. Set it explicitly when you want to control attempted free-charge updates per stored sample, and assess the resulting correlation rather than interpreting a sweep as a pass through independent labels.

## Initialisation and other proposal constructions

The constructive space's `random_state` draws free charges uniformly and reconstructs the others. This gives valid initial configurations independently of the network. The Metropolis chains then approach the current wavefunction distribution, with the discard controlled by the variational state.

The Hilbert API also exposes [free-edge and plaquette move descriptors](../../api/public/neuralqx/hilbert/u1/index.md), including updates in every gauge component. These construct proposed configurations. They are not additional ready-made sampler modes, and calling `hilbert.propose` alone does not perform wavefunction acceptance.

For the supplied sampler, use `MetropolisU1Gauge` and its replacement or adjacency option. To build a different mixture around Hilbert moves, continue with the [custom transition-rule guide](../../developers/samplers/transition-rules.md), where proposal probabilities and preservation of the intended physical sector belong together.
