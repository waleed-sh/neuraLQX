# U(1) spaces

The U(1) spaces assign a finite set of charge labels to each graph edge. They support one U(1) factor or several independent factors, such as the U(1)$^3$ setting used in Abelian models of gravity. You choose the charge range, the number of components per edge, and whether constructive gauge relations restrict the configurations.

[`U1Hilbert`](../../api/public/neuralqx/hilbert/index.md#neuralqx.hilbert.U1Hilbert) provides the unconstrained product basis. [`U1GaugeInvariantHilbert`](../../api/public/neuralqx/hilbert/index.md#neuralqx.hilbert.U1GaugeInvariantHilbert) adds relations between edge charges and reconstructs dependent labels during state generation. Understanding its finite, cyclic arithmetic is part of choosing the model, so this page explains that convention alongside Gauss law.

## Charges as representation labels

An irreducible representation of U(1) is labelled by an integer $q$. For a group element $e^{i\theta}$, its character is

$$
\chi_q(e^{i\theta})=e^{iq\theta},
\qquad q\in\mathbb Z.
$$

On a graph with $E$ edges and $g$ independent U(1) factors, a charge configuration is an array of labels $q_e^{(a)}$, with $a=0,\ldots,g-1$. Before imposing gauge relations, the corresponding functions are products of the edge characters:

$$
\Psi_{\mathbf q}(\boldsymbol\theta)
= \prod_{e=0}^{E-1}\prod_{a=0}^{g-1}
  \exp\!\left(iq_e^{(a)}\theta_e^{(a)}\right).
$$

The infinite integer range is replaced by a finite local set in a simulation. With integer `cutoff=Q` and the default `step=1`, this set is $\{-Q,\ldots,Q\}$, with $d=2Q+1$ labels. The unconstrained basis then has dimension $d^{gE}$.

`gauge_dimensions` counts the independent Abelian components. It is not the spatial dimension of the graph embedding, and setting it to three constructs U(1)$^3$, with its own Abelian representation structure. The [SU(2) space](su2.md) implements the non-Abelian spins and intertwiners separately.

## Construct the unconstrained space

Here each edge of a square carries three charge components:

```python
import jax
import jax.numpy as jnp
import neuralqx as nqx

graph = nqx.graph.Grid2D(2, 2)
hilbert = nqx.hilbert.U1Hilbert(
    graph,
    cutoff=1,
    gauge_dimensions=3,
)
samples = hilbert.random_state(jax.random.key(10), size=8)

print(hilbert.local_space.all_values().tolist())
print(hilbert.size, hilbert.dimension)
print(samples.shape, hilbert.view(samples).edges.shape)
print(hilbert.edge_values(samples, 0).shape)
print(bool(jnp.all(hilbert.is_valid(samples))))
```

```text
[-1, 0, 1]
12 531441
(8, 12) (8, 4, 3)
(8, 3)
True
```

Every locally valid assignment is accepted by this class. It is useful when Gauss law is imposed through the calculation, when comparing constrained and unconstrained formulations, or when studying a model whose edge charges have different restrictions.

Both supplied U(1) constructors use the same scalar range on every edge and component. For different local cutoffs or additional vertex degrees of freedom, start with a [heterogeneous space](local-spaces.md#heterogeneous-edge-and-vertex-domains) and choose constraints, operators, and sampling rules that support that declaration.

The flat layout contains all edges of component zero, then all edges of component one, and so on. Its site index is $aE+e$. `view(samples).edges` exposes shape `(..., E, g)` when $g>1$. For one component, it has shape `(..., E)`, without an extra axis of length one. There are no separate vertex labels in these U(1) constructors. See [State layouts](state-layouts.md) for batch conventions and index conversion.

### Choose the local range

The more general range has spacing `step`, a length of `2 * cutoff / step + 1`, and a start determined by `positive_qn` and `qn_start`. The ratio `2 * cutoff / step` must be an integer. Use positive spacing for the usual increasing charge convention.

```python
import neuralqx as nqx

graph = nqx.graph.Grid2D(2, 2)
spaces = {
    "symmetric": nqx.hilbert.U1Hilbert(graph, cutoff=2),
    "nonnegative": nqx.hilbert.U1Hilbert(graph, cutoff=2, positive_qn=True),
    "shifted": nqx.hilbert.U1Hilbert(
        graph, cutoff=2, positive_qn=True, qn_start=1,
    ),
    "spacing two": nqx.hilbert.U1Hilbert(graph, cutoff=2, step=2),
}

for name, hilbert in spaces.items():
    print(name, hilbert.local_space.all_values().tolist())
```

```text
symmetric [-2, -1, 0, 1, 2]
nonnegative [0, 1, 2, 3, 4]
shifted [1, 2, 3, 4, 5]
spacing two [-2, 0, 2]
```

`positive_qn=True` shifts the range while retaining its cardinality. At cutoff two, it gives five labels beginning at zero. `qn_start` changes that starting value only when `positive_qn=True`. The properties `q_min`, `q_max`, `q_step`, and `local_size` expose the resolved range.

These arguments change the actual stored values. If a shifted value is intended only as an encoding of a physical charge, account for that interpretation consistently in your operators and constraints. Integer charges give the standard U(1) characters above. The unconstrained implementation also accepts compatible floating point ranges, but that numerical flexibility does not establish a new U(1) representation convention for your model. The constructive constrained class requires integer `cutoff` and `step` arguments.

## Gauss law on an oriented graph

For the usual charge basis without external vertex charges, define the incidence matrix by $B_{ve}=+1$ when edge $e$ starts at vertex $v$ and $B_{ve}=-1$ when it ends there. An edge returning to the same vertex contributes once with each sign. The untruncated U(1) Gauss condition is

$$
G_v^{(a)} = \sum_e B_{ve}q_e^{(a)}=0
\qquad\text{for every }v\text{ and }a.
$$

This balances outgoing and incoming charge at each vertex. Edge direction therefore matters even though it does not change the number of available local labels. Review the [graph orientation conventions](../graphs/labels.md) when importing a graph or writing explicit relations.

For a connected graph without self loops, `auto_constraint=True` derives constructive relations by choosing a spanning tree and solving its edge charges in terms of the remaining edges. Those remaining edges are independent, while the tree edges are reconstructed. In the finite implementation, the reconstruction uses the wrapped arithmetic described in the next section.

```python
import jax
import jax.numpy as jnp
import neuralqx as nqx

graph = nqx.graph.Grid2D(2, 2)
hilbert = nqx.hilbert.U1GaugeInvariantHilbert(
    graph,
    cutoff=2,
    gauge_dimensions=3,
    auto_constraint=True,
)
samples = hilbert.random_state(jax.random.key(11), size=8)

print(hilbert.topology.n_free)
print(hilbert.size, hilbert.dimension)
print(samples.shape)
print(bool(jnp.all(hilbert.is_valid(samples))))
print(hilbert.is_indexable)
```

```text
1
12 125
(8, 12)
True
False
```

The square has one independent cycle. Each of the three components therefore has one freely chosen charge, giving $5^3=125$ states. More generally, the connected graph construction leaves $F=E-V+1$ independent edge labels per component and has constructive dimension

$$
\dim\mathcal H_{\mathrm{constructive}}=d^{gF}.
$$

The configuration still stores all $gE$ entries. This is important for operators, which need the reconstructed edge charges as well as the independent ones. Automatic construction requires a connected graph. Explicit relations are available when you need to control which edges are independent or impose a different boundary condition.

## What the finite cutoff means

For the standard range $\{-Q,\ldots,Q\}$, the reconstruction maps an integer $x$ back into the allowed range using

$$
\operatorname{wrap}_Q(x)
= -Q + \big((x+Q)\bmod(2Q+1)\big).
$$

A dependent charge obeys $q_s=\operatorname{wrap}_Q(\sum_e c_e q_e)$, with coefficients $c_e=\pm1$. At this cutoff, the relation is a congruence modulo $2Q+1$. When the signed sum stays inside the range it agrees with ordinary addition. When it crosses the boundary it wraps. This is a cyclic finite regularisation of the charge arithmetic, and its accepted configurations can differ from an ordinary integer Gauss law with a hard cutoff.

For example, at $Q=2$, the sum $2+2=4$ wraps to $-1$. On three parallel edges with the first orientation opposite to the other two, that produces the following valid configuration for the supplied constructive space:

```python
import jax.numpy as jnp
import neuralqx as nqx

a, b = (0, 0, 0), (1, 0, 0)
graph = nqx.graph.Graph(
    [(a, b, 0), (b, a, 1), (b, a, 2)],
    is_planar=True,
)
hilbert = nqx.hilbert.U1GaugeInvariantHilbert(
    graph,
    cutoff=2,
    auto_constraint=True,
)
state = jnp.array([-1, 2, 2])
integer_gauss = state[0] - state[1] - state[2]

print(bool(hilbert.is_valid(state)))
print(int(integer_gauss))
print(int(integer_gauss % hilbert.local_size))
```

```text
True
-5
0
```

If your calculation requires ordinary integer charge conservation, construct a generic space with [linear Gauss constraints](constraints.md#weighted-relations-and-charge-conservation). Choose a sampler and operators that implement that same boundary convention. The U(1) constructive dimension formula above belongs to the cyclic relations and is not a count for an arbitrary integer constrained truncation.

For a general local range, wrapping converts the signed sum into a local index relative to `q_min` and `q_step`, rounds to the nearest index, reduces it modulo `local_size`, and converts back to a value. The symmetric integer range with unit spacing gives the direct modular interpretation above. A shifted or more widely spaced range needs its own consistent physical interpretation.

## Supply and inspect your own relations

The argument is named `gauge_fixing`, following the API's convention for reconstructing dependent edge charges. Each item has the form `[[dependent_edge], [source_edges]]`. The relation is applied to every gauge component independently. In the following directed triangle, $q_0=q_2$ and $q_1=q_2$ impose charge conservation around the cycle:

```python
import jax.numpy as jnp
import neuralqx as nqx

a, b, c = (0, 0, 0), (1, 0, 0), (0, 1, 0)
graph = nqx.graph.Graph([(a, b), (b, c), (c, a)], is_planar=True)
hilbert = nqx.hilbert.U1GaugeInvariantHilbert(
    graph,
    cutoff=2,
    gauge_fixing=[
        [[0], [2]],
        [[1], [2]],
    ],
)
candidate = jnp.array([2, -2, 1])
restored = hilbert.reimpose_gauge_fixing(candidate)

print(hilbert.topology.free)
print(hilbert.dimension)
print(restored.tolist())
print(bool(hilbert.is_valid(restored)))
```

```text
(2,)
5
[1, 1, 1]
True
```

The free charge on edge two is preserved. The other two entries are recomputed from it. `reimpose_gauge_fixing` is a constructive operation on configuration labels, rather than an orthogonal projector acting on a wavefunction. Its input should already have locally valid free charges.

Source lists add their entries. A signed string such as `"-2"` subtracts edge two. Thus, the small declaration `[[0], [1, "-2"]]` means that edge zero is reconstructed from edge one minus edge two. The legacy `"N"` token changes subsequent terms to subtraction. Signed edge references make the meaning more local and easier to inspect. Integer indices or canonical edge objects can identify graph edges, as described in the [graph label guide](../graphs/labels.md).

Each dependent edge may appear on the left only once. Relations can depend on other reconstructed edges, provided those dependencies contain no cycle. Construction resolves their order and rejects cyclic dependencies. Use `gauge_fixing_pretty()` to display the resolved relations, and inspect `topology.free` to see which edges remain independent.

Supply either `gauge_fixing` or `auto_constraint=True`. The constrained class needs one of them. With explicit input, it checks the relations you supply, so you are responsible for ensuring that they implement all the intended vertex or boundary conditions. An incomplete set of relations does not acquire the remaining Gauss conditions automatically.

## Generate configurations and continue the calculation

For the unconstrained class, `random_state` draws directly from the local charge range. The constructive class draws independent charges and reconstructs the dependent ones. This avoids rejecting arbitrary full configurations until one happens to satisfy all the relations. Both accept the standard leading batch shape described in [State layouts](state-layouts.md).

Use `is_valid` for complete membership checks. `check_states` and `is_gauge_invariant` on the constrained U(1) class check the resolved relations, while `is_valid` also checks the local range. The exact constructive dimension is available, but generic constrained ranking and `all_states` are not. Knowing the number of configurations does not imply that the implementation stores or indexes their full basis.

For wavefunction sampling, [`MetropolisU1Gauge`](../../api/public/neuralqx/sampler/index.md#neuralqx.sampler.MetropolisU1Gauge) provides the U(1) sampler entry point. The space also exposes free edge and plaquette proposals that restore its constructive relations after the U(1) update. A proposal is one part of the sampling algorithm, while the sampler uses the wavefunction to determine acceptance. Continue with the [sampler guide](../samplers/index.md), or use the space to construct a [U(1) LQX model](../lqx/u1.md) and its operators.
