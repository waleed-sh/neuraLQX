# U(1) models

The U(1) models describe charge networks on a fixed graph. Their operators act on the edge charges supplied by a [U(1) Hilbert space](../hilbert/u1.md). This page introduces the shared charge, holonomy, Gauss, and curvature operators, and explains the single component model. The guides for the [2+1 weak coupling limit](wcl-planar.md) and [3+1 weak coupling limit](wcl-spatial.md) then develop the geometric operators and Thiemann constraints of the U(1)$^3$ weak coupling models.

[`LqxWCL1D`](../../api/public/neuralqx/lqx/index.md#neuralqx.lqx.LqxWCL1D), also exported as `LqxWCL`, requires one gauge component. [`LqxWCL3D`](../../api/public/neuralqx/lqx/index.md#neuralqx.lqx.LqxWCL3D) and [`LqxWCL4D`](../../api/public/neuralqx/lqx/index.md#neuralqx.lqx.LqxWCL4D) require three. The latter describe weak coupling constructions in $2+1$ and $3+1$ spacetime dimensions respectively. A choice of gauge component count therefore has a physical role, beyond determining the length of the state array.

## Charges and finite cutoffs

Write a configuration as $q=(q_e^{(c)})$, where $e$ labels an edge and $c$ labels a U(1) component. The usual centred local range is

$$
q_e^{(c)}\in\{-Q,-Q+h,\ldots,Q\},
$$

with spacing $h$. In the default integer construction, $h=1$. The flat state array stores the components in the [layout defined by the Hilbert space](../hilbert/state-layouts.md). Use the layout to locate a particular edge and component instead of assuming that the three values of an edge occupy adjacent positions.

The shared [`NumberOperator`](../../api/public/neuralqx/operator/prebuilt/wcl/index.md#neuralqx.operator.prebuilt.wcl.NumberOperator) and [`IdentityOperator`](../../api/public/neuralqx/operator/prebuilt/wcl/index.md#neuralqx.operator.prebuilt.wcl.IdentityOperator) are diagonal,

$$
\hat q_e^{(c)}|q\rangle=q_e^{(c)}|q\rangle,
\qquad
I_a|q\rangle=a|q\rangle.
$$

Construct them through `model.number(edge, copy=c)` and `model.identity(const=a)`. Here `copy` is a zero-based component index. These methods return operators and do not select a model property.

## Edge and loop holonomies

The weak coupling operators use cyclic shifts. Let $W$ wrap a charge back into its finite local range, and let $\mathbf e_{e,c}$ select one edge and component. It is useful to state the convention in terms of the matrix rows returned by `get_conn_padded`:

$$
\langle q|R_{e,c}|q'\rangle
=\delta_{q',\,W(q+h\mathbf e_{e,c})}.
$$

Thus `get_holonomy(edge, copy=c)` returns a positive shift of the *connected configuration* in a matrix row. Acting on a ket, the same operator shifts the charge in the opposite direction. Its adjoint reverses the row shift. This distinction matters when comparing a connectivity array with a ket-action equation.

Here is the cutoff boundary on a triangle with charges $-1,0,1$.

```python
import neuralqx as nqx
import jax.numpy as jnp

a, b, c = (0, 0, 0), (1, 0, 0), (0, 1, 0)
graph = nqx.graph.Graph([(a, b), (b, c), (c, a)], is_planar=True)
hilbert = nqx.hilbert.U1Hilbert(graph, cutoff=1)
model = nqx.lqx.LqxWCL1D(hilbert)

edge = graph.edges[0]
site = hilbert.layout.edge_site(edge)
state = jnp.zeros(hilbert.size, dtype=jnp.int32).at[site].set(1)

connected, elements = model.get_holonomy(edge).get_conn_padded(state)
_, charge = model.number(edge).get_conn_padded(state)
print(int(connected[0, site]), float(elements[0]))
print(float(charge[0]))
```

```text
-1 1.0
1.0
```

The [`U1HolonomyOperator`](../../api/public/neuralqx/operator/prebuilt/wcl/index.md#neuralqx.operator.prebuilt.wcl.U1HolonomyOperator) wraps $1$ to $-1$ here. It does not discard the transition. On the unconstrained product space this cyclic shift is unitary. If you work in a constrained space, also check that your chosen operator preserves that space. An open edge shift is not generally a gauge invariant operation.

For a dressed loop $\alpha$, let $\ell_{\alpha,e}$ be $+1$ when its traversal follows the stored edge and $-1$ when it opposes it. [`MinimalLoopHolonomyOperator`](../../api/public/neuralqx/operator/prebuilt/wcl/index.md#neuralqx.operator.prebuilt.wcl.MinimalLoopHolonomyOperator) applies the corresponding simultaneous row shift in one component,

$$
\langle q|R_{\alpha,c}|q'\rangle
=\delta_{q',\,W(q+h\ell_{\alpha,c})}.
$$

Obtain dressed loops from `graph.dressed_minimal_loops()` and pass one to `model.minimal_loop_holonomy(loop, copy=c)`. The [connectivity and loops guide](../graphs/connectivity.md) explains their orientation and representation.

### Three component holonomies

In the U(1)$^3$ models, the default `dimension=3` returns a sum of three independent component actions,

$$
R_e^{(3)}=\sum_{c=0}^{2}R_{e,c},
\qquad
R_\alpha^{(3)}=\sum_{c=0}^{2}R_{\alpha,c}.
$$

It does not shift all three components in one transition. The underlying classes are [`NDU1HolonomyOperator`](../../api/public/neuralqx/operator/prebuilt/wcl/index.md#neuralqx.operator.prebuilt.wcl.NDU1HolonomyOperator) and [`NDMinimalLoopHolonomyOperator`](../../api/public/neuralqx/operator/prebuilt/wcl/index.md#neuralqx.operator.prebuilt.wcl.NDMinimalLoopHolonomyOperator). Use `dimension=1, copy=c` to select a single component. `copy` does not select a component when `dimension=3`.

```python
import neuralqx as nqx
import jax.numpy as jnp

graph = nqx.graph.K5Graph()
hilbert = nqx.hilbert.U1Hilbert(graph, cutoff=1, gauge_dimensions=3)
model = nqx.lqx.LqxWCL4D(hilbert)
state = jnp.zeros(hilbert.size, dtype=jnp.int32)

all_components = model.get_holonomy(graph.edges[0])
one_component = model.get_holonomy(graph.edges[0], dimension=1, copy=2)
all_connected, _ = all_components.get_conn_padded(state)
one_connected, _ = one_component.get_conn_padded(state)
print(all_connected.shape[0], one_connected.shape[0])
```

```text
3 1
```

## Curvature and the single component model

For one loop and component, [`OneMinusHalfHolonomyOperator`](../../api/public/neuralqx/operator/prebuilt/wcl/index.md#neuralqx.operator.prebuilt.wcl.OneMinusHalfHolonomyOperator) constructs

$$
B_{\alpha,c}=I-\frac12\left(R_{\alpha,c}+R_{\alpha,c}^\dagger\right).
$$

Use `model.one_minus_half_holonomy(loop, copy=c)`. The unnormalised BF curvature sum is

$$
C_{\mathrm{BF}}
=\sum_{\alpha\in\mathcal L}\sum_c
\left(2I-R_{\alpha,c}-R_{\alpha,c}^\dagger\right).
$$

Each term equals $(R_{\alpha,c}-I)(R_{\alpha,c}^\dagger-I)$ on the unconstrained cyclic product space. The operator is positive and already measures squared holonomy defects. The component sum has one term per loop in `LqxWCL1D` and three in the U(1)$^3$ models.

`model.curvature_constraint` caches the default operator. `LqxWCL1D` returns $C_{\mathrm{BF}}$, preserving its existing normalization. `LqxWCL3D` and `LqxWCL4D` return $C_{\mathrm{BF}}/|\mathcal L|$, averaging over loops while summing the three gauge copies. Call `model.get_curvature_constraint(normalize=True)` for an average or `normalize=False` for a sum in any WCL model.

The default selection uses the graph's dressed minimal loops. These are the graph's shortest loops, not a general cycle basis. Call `model.get_curvature_constraint(loops=[...])` to select a different set of dressed loops. An empty selection gives the zero operator. This getter replaces the former `model.curvature_constraint(...)` factory call.

In `LqxWCL1D`, this curvature operator is the default Euclidean component and the default total constraint. No Lorentzian, area, volume, or mass operator is supplied. The total curvature is treated as one unlabelled block, so its default quadratic constraint is $C_{\mathrm{BF}}^2$. It is not a sum of individually squared loop contributions.

```python
import neuralqx as nqx
import numpy as np

a, b, c = (0, 0, 0), (1, 0, 0), (0, 1, 0)
graph = nqx.graph.Graph([(a, b), (b, c), (c, a)], is_planar=True)
hilbert = nqx.hilbert.U1Hilbert(graph, cutoff=1)
model = nqx.lqx.LqxWCL1D(hilbert)

curvature = np.asarray(model.constraint.to_dense())
np.testing.assert_allclose(curvature, curvature.conj().T)
print(bool(np.linalg.eigvalsh(curvature).min() > -1e-12))
```

```text
True
```

## The Gauss constraint

All three models provide [`GaussConstraintOperator`](../../api/public/neuralqx/operator/prebuilt/wcl/index.md#neuralqx.operator.prebuilt.wcl.GaussConstraintOperator) through `gauss_constraint()` or its alias `gauss()`. Define the oriented residual

$$
G_v^{(c)}(q)
=\sum_{e\,\text{incoming at }v}q_e^{(c)}
-\sum_{e\,\text{outgoing from }v}q_e^{(c)}.
$$

The returned operator is the diagonal *squared* violation,

$$
\mathcal G|q\rangle
=\left[\sum_{v,c}\bigl(G_v^{(c)}(q)\bigr)^2\right]|q\rangle.
$$

A self-loop contributes once to each incidence sum and cancels. With `modular=True`, the residual is first wrapped into the finite local charge range before it is squared. For the usual centred integer range, this tests Gauss law modulo $2Q+1$.

This choice matters when using a [gauge invariant U(1) space](../hilbert/u1.md). Its finite cyclic constraint can admit a state whose ordinary integer residual is nonzero. Use the Gauss operator that matches the condition you intend to test. Neither version is automatically added to the model's default Hamiltonian. The Hilbert space restriction, a measured Gauss violation, and a Gauss penalty in the objective are separate choices.

For the U(1)$^3$ geometric and Hamiltonian operators, continue with the [2+1 weak coupling limit](wcl-planar.md) or the [3+1 weak coupling limit](wcl-spatial.md).
